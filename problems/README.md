# Mathathon Round 1: Problems

Each team chooses one problem from this list ([Participant Rules §3](../rules/participant-rules.md#3-problem-selection)). At most 4 teams can sign up for each problem.

Some problems have an official Lean statement, marked ✓ below. If you claim to have formalized the main theorem of such a problem, prove the official statement without changing it ([Submission Guidelines §5](../rules/submission-guidelines.md#5-lean-project-optional)). The statements are in [`lean/`](lean/), a Lean project for Lean v4.35.0 and Mathlib `v4.35.0`. To check them, run `lake exe cache get` and then `lake build` in that folder.
