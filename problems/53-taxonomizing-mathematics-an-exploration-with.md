# 53 · Taxonomizing mathematics: an exploration with minimal surfaces

**Tracks:** Geometry · **Area:** Geometry/geometric measure theory

## Description

Develop a framework for organizing mathematical objects and existing results for human and machine exploration. Using minimal surfaces as an initial test case, the proposal is to: (1) consolidate known examples, constructions, and theorems; (2) encode geometric invariants, hypotheses, conclusions, and relationships in a machine-readable form designed for computational efficiency; (3) analyze the resulting data to uncover subtle connections and patterns across the literature; and (4) build interactive software enabling mathematicians to explore these structures. Periodic minimal surfaces, with their rich lattice symmetries and topology, offer a further example. The central objective is deeper human understanding through computational exploration.

## Desired outcome

Interactive software and a data set that can be used for human exploration and understanding

This problem is not necessarily tied to minimal surfaces. Other geometric objects could be considered.
